# 📘 Currency Converter CLI

A simple command-line currency converter built in C++ using `libcurl` for API calls and `nlohmann/json` for parsing exchange rates.

<img width="1041" height="526" alt="image" src="https://github.com/user-attachments/assets/a526b508-7c8b-4282-8fa4-87a579ccbb3f" />

## 🚀 Features

* Convert between 20+ major world currencies
* Live exchange rates from online API
* Clean terminal UI with centered text
* Cross-platform (Linux, macOS, Windows)

## 📦 Requirements

* C++20 compiler
* CMake
* `libcurl`
* `nlohmann/json`

## 🔧 Build & Run

```bash
cmake .
make
./currency_converter_cli
```
